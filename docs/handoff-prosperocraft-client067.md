is roughly30seconds. They requested a GitHub release, then sound, before further
instructions. No further performance tuning is part of this turn.

checksums verified; the downloaded corresponding-source/relink kit reproduced the
accepted native ELF. See [publication evidence](validation/client066-release-publication.json).

after Minecraft logs Stopping; that does not establish a crash or clean lifecycle.

measured FPS, full hardware utilization, save/reload, audio or endurance.

backed-up options migration for the old muted launcher defaults. Working C1,
controls, heap, graphics settings and official game files are retained.
See [implementation and console test guide](client-audio-067.md) and
[checked build record](validation/client067-audio-build-2026-10-26.json).
