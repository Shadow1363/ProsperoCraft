# Instances-only launcher — 01.000.095

The user's final steering for this build is to leave out Home.095 starts directly
on Instances, with Settings and Sign in/player account as the other two tabs.
L1/R1 automatically selects their actual content. Header focus still suppresses
content selection to avoid the competing Settings outline from093.

Instances always ends with a plus-only add card. An empty library has one large
card containing only its plus. X opens creation; the top bar does not open the
creation page.095 keeps permanent No / Yes, Delete confirmation without Undo,
and the simplified six-essential PLAY tutorial plus the five-page full OPTIONS
guide. OPTIONS from the tutorial retains its preparation/OK gate.

Home, favorite browsing/pinning and quick-play UI entry points are deferred for
this candidate. The original094 source commit and exact candidate are preserved.
Existing favorite metadata and its bounded read-only inventory helpers are kept,
but095 does not expose Home or pass quick-play arguments. Stored accounts, worlds,
verified downloads and shared cache use the same paths. No network/runtime changes;
hosting remains deferred at the user's request.

Host checks cover three-tab navigation/wrapping, initial Instances, final plus
pagination, single focus, guide paging/return/preparation gate, account and full
launch policy, permanent deletion/recovery and existing download/haptics/background
behavior. Native and actual Vulkan previews include the three-tab header and
single Settings focus; pixel-centering checks pass. Package checks verify matching
classes, native/source/runtime hashes, signatures and preservation of older builds.
These do not establish PS5 UI feel, deletion/purge or game lifecycle success.
Test permanent deletion with a disposable instance. No console ALL PASS, Store,
release asset or new frozen milestone is inferred.
