# Client LWJGL Core 01.000.002

Client002 adds an eighth row that executes actual upstream LWJGL3.4.3 native memory/JNI APIs and a PS5 resident SharedLibrary provider. ClientFoundation000 and ClientNativeLoading001 remain frozen ALL PASS milestones. TitlePPSA99874 is retained, with the independent client version counter. All eight rows passed on the actual PS5, confirmed by the human tester on 2026-10-23. Source, validation and matching package are frozen in `Client_LWJGL_Core/`.

The native subset is built from pinned upstream commit `30fac9b95f99cda97312232be25ba55297bf9951`. Source file SHA-256 pins are in `client/ports/lwjgl/native-sources.json`. It includes common initialization/TLS, page/cache queries, generated JNI calls, memory access, JNI native-interface functions and libc allocation/string wrappers. Libffi callbacks, desktop native loaders, renderer/audio libraries and complete LWJGL native coverage are not included. Unimplemented native methods remain unavailable rather than returning fake success.

PS5 adaptations use the OS page-size query and x86 CPUID cache-line query. TLS-key creation failure returns JNI_ERR; a valid key0 is cleaned up correctly. The native subset uses baseline x86-64/SSE2 without AVX/AVX2/FMA. Existing unrelated native groups/SDK libraries are unchanged. Source/object/adaptation hashes are recorded in the package's native audit.

The dependency Java port now implements `org.lwjgl.system.ps5.PS5Library`. APIUtil returns this provider on PS5. It opens only registered resident libraries, resolves real exported addresses, returns0 for absent symbols and reports unavailable libraries honestly. Its path is null because the resident registry is not an independently loaded file. Closed-handle operations fail; close is idempotent, while code remains resident. This extends the earlier platform port, leaving every other upstream JAR entry unchanged except12 recompiled/added classes and the retained license. The original official client and all54 original client/Java JARs remain intact.

The probe explicitly enables unnamed-module native access and exports `java.base/jdk.internal.misc` to LWJGL's Java25 Unsafe backend. Its supported system-allocator configuration exercises actual SDK libc allocation; jemalloc, large-allocation pressure and callback support are not established by this test. There is no OS-name or game-version spoofing and no game-JAR rewrite.

Run all eight rows in order: runtime initialization; VM creation; original-artifact/class preflight; PS5 platform/provider absence check; JNI direct buffers; standard resident JNI loading; **LWJGL core/memory/provider**; VM destruction. The new row checks allocation/reallocation/calloc/alignment/free, typed native views/copy, Unicode conversion, MemoryStack scopes, actual generic JNI calls through malloc/free addresses, and real SharedLibrary symbol lookup/function invocation. Missing/malformed names and closed resources must fail. Graphics and Minecraft main are not invoked.

Host tests pass with actual upstream native code in a real Java25 interpreter JVM, XcheckJNI and UBSan. The JVM retains ownership of its signal handlers so sanitizer signal interception does not interfere with Java's implicit exceptions. The host-only paired JAR carries the actual rebuilt host-library digest; hash checking is not disabled and the production/original JARs remain unchanged. A separate actual-source ASan/UBSan test covers TLS key0, creation failure and cleanup. Desktop platform/ordinal controls also pass. Host-native calls do not validate PS5 CPU/syscall availability; the eight-row target test subsequently passed on PS5.

Target compilation/package checks pass: signatures/CRC, title/version/options,54 upstream pins, exact dependency JAR delta, both resident groups' actual JNI/export symbols and object-hash inventories, CPUID/baseline code inspection, current runtime/module image and package/symbol copies. Frozen000/001 and Fabric094/Paper108 package hashes remain preserved. The core subset and provider are now the frozen Client_LWJGL_Core ALL PASS milestone; this does not validate full binding coverage or graphics.

Local package SHA-256 is recorded in `client/build-status.json` and `dist/client/SHA256SUMS`. The package uses the same app ID as the server and replaces the installed app. Keep it open for logs after the rows. Next: native GPU presentation and SDL/Vulkan integration. Server two-hour endurance remains deferred.
